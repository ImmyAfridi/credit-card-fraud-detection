# Credit Card Fraud Detection

## Overview
A machine learning classification project to identify potentially fraudulent credit card transactions.

## Dataset
The dataset contains anonymized credit card transactions made by European cardholders in September 2013. The target column, `Class`, indicates whether a transaction is legitimate (`0`) or fraudulent (`1`).

Dataset source: [Kaggle — Credit Card Fraud Detection](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)

## Project Goals
- Explore the transaction data and class imbalance.
- Prepare data for machine learning.
- Compare classification models.
- Evaluate precision, recall, F1-score, and confusion matrices.
- Investigate decision-threshold tuning for fraud detection.
